# mobile

Native and cross-platform mobile clients.

## Detection signals

- Xcode projects (.xcodeproj, .xcworkspace), Gradle/AndroidManifest.xml
- React Native, Flutter/Expo manifests

## Stack quick-map

- iOS/Android/RN/Flutter app → mobile (+ backend categories for its API)
- App stores credentials, tokens or personal data → authentication, secrets-crypto, compliance-privacy
