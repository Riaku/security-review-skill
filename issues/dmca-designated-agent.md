# DMCA Designated Agent for User Uploads

**MUST** register a designated DMCA agent and operate a notice-and-takedown workflow before a service accepts user-uploaded content.

**Why:** Without a registered agent and a working takedown path the operator forfeits safe harbor and faces statutory damages — up to $150K per willfully infringed work — for content it merely hosts.
**Detect:** check for a published DMCA or abuse contact, a current US Copyright Office registration, and a takedown intake with counter-notice handling; flag any upload feature that shipped without all three.
**References:** 17 U.S.C. §512(c)(2), https://www.law.cornell.edu/uscode/text/17/512, https://dmca.copyright.gov/
